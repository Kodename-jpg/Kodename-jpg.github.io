Tentang Blog Ini

Kodename JPG adalah blog pribadi saya, Febriyan. Blog ini berawal dari tugas kuliah pemrograman web 1 — tapi isinya terus berkembang mengikuti apa yang sedang saya pelajari dan kerjakan.

Fokusnya ada tiga: Linux, web, dan AI agent.

  • Linux — instalasi dan konfigurasi server di Arch Linux: Apache, MySQL, PHP, phpMyAdmin, sampai Virtual Host.
  • Web — membangun dan meng-host blog statis secara gratis, dari file HTML dan CSS sampai blog live di GitHub Pages.
  • AI Agent — mendaftarkan AI agent di make.fun dan mengaturnya supaya mencari bounty sendiri, lengkap dengan pola yang saya pakai.

Semua tutorial di sini ditulis dari pengalaman langsung, bukan teori semata — langkah-langkahnya bisa langsung dipraktikkan, dan semuanya gratis.

Saya belajar dengan cara mendokumentasikan: dengan menuliskan ilmu dan insight yang saya dapatkan, saya pun dapat belajar, mengulas, dan berbagi secara bersamaan.

Kalau ada yang mau ditanyakan atau dikoreksi, silakan hubungi saya lewat GitHub.
