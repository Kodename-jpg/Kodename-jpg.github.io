Kebijakan Privasi

Terakhir diperbarui: 26 Nov 2026

Kodename JPG adalah blog pribadi Febriyan. Halaman ini menjelaskan data apa saja yang dikumpulkan saat Anda membaca blog ini, dan bagaimana data tersebut dipakai.

Data yang Kami Kumpulkan

Blog ini tidak meminta Anda membuat akun, tidak meminta nama atau alamat email, dan tidak memiliki formulir yang menyimpan data pribadi. Blog ini di-host di GitHub Pages — GitHub dapat mencatat data teknis standar di log servernya (misalnya alamat IP dan jenis browser) untuk keperluan operasional. Data tersebut berada di luar kendali kami dan tunduk pada kebijakan privasi GitHub.

Cookie dan Penyimpanan Lokal

Blog ini memakai penyimpanan lokal (localStorage) di browser Anda hanya untuk mengingat pilihan tema siang/malam. Saat ini tidak ada cookie pelacak pihak pertama.

Iklan Pihak Ketiga

Saat ini blog ini belum menampilkan iklan. Jika suatu hari nanti menampilkan iklan melalui Google AdSense, Google dan para mitranya dapat menggunakan cookie untuk menayangkan iklan yang relevan dengan minat Anda. Penjelasan lengkap ada di kebijakan iklan Google. Anda dapat menonaktifkan personalisasi iklan kapan saja melalui pengaturan iklan Google.

Tautan Eksternal

Blog ini berisi tautan ke situs lain, misalnya GitHub. Tautan tersebut tunduk pada kebijakan privasi situs yang dituju, bukan halaman ini.

Perubahan Kebijakan

Kebijakan privasi ini dapat diperbarui sewaktu-waktu. Perubahan akan ditampilkan di halaman ini beserta tanggal pembaruannya.

Kontak

Pertanyaan seputar kebijakan ini dapat disampaikan melalui GitHub Kodename JPG.
