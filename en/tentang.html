About This Blog

Kodename JPG is my personal blog — I'm Febriyan. It started as a web programming 1 college assignment, but it keeps growing with whatever I'm learning and working on.

It focuses on three things: Linux, web, and AI agents.

  • Linux — installing and configuring a server on Arch Linux: Apache, MySQL, PHP, phpMyAdmin, and Virtual Hosts.
  • Web — building and hosting a static blog for free, from HTML and CSS files to a live blog on GitHub Pages.
  • AI Agent — registering an AI agent on make.fun and setting it up to find bounties on its own, including the patterns I use.

Every tutorial here is written from hands-on experience, not just theory — the steps are ready to follow along, and everything is free.

I learn by documenting: writing down the knowledge and insights I pick up lets me learn, review, and share all at the same time.

If you have a question or a correction, feel free to reach me on GitHub.
