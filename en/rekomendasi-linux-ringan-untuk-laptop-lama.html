An old laptop doesn't mean a dead laptop. Most "potato" laptops are slow not because the hardware is broken, but because the operating system is too heavy for the specs. Switch to a lightweight Linux, and a 10–15-year-old laptop can still handle browsing, typing, videos, and light work.

This tutorial lists 6 Linux distros with small ISO files and low RAM needs that are still actively maintained in 2026. All of them are free, and all of them can be tried first from a live USB before installing.

Figure 1: Minimum RAM per distro (MB) — smaller is lighter.


How to Choose Quickly



Under 1 GB of RAM → antiX or Puppy Linux.
1–2 GB of RAM → Bodhi or MX Linux.
2–4 GB of RAM → Lubuntu or Linux Lite.
Still on a 32-bit laptop → antiX, Puppy, or MX Linux.
Just moved from Windows → Linux Lite or MX Linux.

1. antiX 26


The antiX Linux logo.


The lightest pick for the oldest hardware. antiX is based on Debian Stable without systemd, uses the extremely frugal IceWM window manager, and still supports 32-bit processors.
Minimum RAM: 256 MB (512 MB recommended) · ISO size: ±2.2 GB (full edition; smaller base and core editions exist) · 32-bit: Yes · Base: Debian Stable (no systemd) · Desktop: IceWM
Best for: laptops with under 1 GB of RAM and 32-bit machines.
Download from the official site

2. Puppy Linux (BookwormPup64)


The Puppy Linux logo.


The smallest ISO — it runs straight from RAM. Puppy Linux boots into RAM, so once it's loaded, the speed of the hard drive barely matters anymore. Great for live USBs and laptops with a failing hard drive.
Minimum RAM: 256–512 MB · ISO size: ±300–400 MB · 32-bit: Yes · Base: Debian/Ubuntu (depends on the edition) · Desktop: JWM
Best for: live USBs, laptops with a failing hard drive, and rescue work.
Download from the official site

3. Bodhi Linux 7.0


The Bodhi Linux 7.0 desktop.


Lightweight but still good-looking. Bodhi Linux uses the Moksha desktop, which looks neat, on top of an Ubuntu LTS base, so package availability is huge.
Minimum RAM: 512 MB · ISO size: ±1.3 GB · 32-bit: No (7.0 is 64-bit only) · Base: Ubuntu LTS · Desktop: Moksha
Best for: 1–2 GB laptops that should still look polished.
Download from the official site

4. MX Linux


The MX Linux logo.


The best balance: light but complete. MX Linux is based on Debian Stable with the XFCE desktop — light enough for a 2 GB machine, yet polished enough for daily use.
Minimum RAM: 1 GB · ISO size: ±2–3 GB · 32-bit: Yes (MX-23) · Base: Debian Stable · Desktop: XFCE
Best for: daily use on 1–2 GB laptops.
Download from the official site

5. Lubuntu 26.04 LTS


The Lubuntu logo.


The lightest official Ubuntu. Lubuntu is an official Ubuntu flavor with the LXQt desktop — the same commands and repositories as Ubuntu, but far lighter on resources. Long-term support until April 2029.
Minimum RAM: 1 GB · ISO size: ±3.9 GB · 32-bit: No · Base: Ubuntu LTS · Desktop: LXQt
Best for: people who already know Ubuntu and want long-term support.
Download from the official site

6. Linux Lite 7.x


The Linux Lite logo.


The closest to Windows, the easiest for beginners. Linux Lite is based on Ubuntu LTS with the XFCE desktop, designed so Windows users feel at home right away: taskbar at the bottom, a Start-like menu, and a clear installer.
Minimum RAM: 1 GB (2 GB for comfort) · ISO size: ±2.9 GB · 32-bit: No · Base: Ubuntu LTS · Desktop: XFCE
Best for: former Windows users switching to Linux for the first time.
Download from the official site

What Didn't Make the List



- Tiny Core Linux — the smallest ISO of all (±20 MB for the Core edition), but it's a distro for advanced users: no full desktop included, almost everything is installed manually.
- Alpine Linux — small and fast, but built for servers and containers, not for a beginner desktop.
- Xubuntu — still in the lightweight family, but it needs 4 GB of RAM or more to feel comfortable, so it doesn't make this list for potato laptops.

Tips



- Try a live USB first before installing — boot from the flash drive and feel the speed yourself. How to make a bootable USB is covered in the How to Make a Bootable Ventoy USB tutorial.
- Check first whether your laptop is 32-bit or 64-bit — pick the wrong ISO and the installer won't run.
- Back up your important data before installing — installation erases the disk.
- Modern browsers are still RAM-hungry — on a 1 GB laptop, close tabs you don't use and don't open too many at once.
