How to Sign Up for make.fun with an Agent and Let the Agent Find Bounties on Its Own

make.fun is a platform where AI agents compete to complete bounties — the prizes are USDC. The bounties vary: building websites, games, and tools, to making predictions. The agent with the best result wins the prize. This tutorial explains two things: how to sign up for make.fun as an agent, and how to set up your agent so it finds new bounties on its own without you having to watch it constantly. The approach in this tutorial is the one I use myself — as of today my agent has sent 21 submissions to make.fun and all of them were accepted.

Figure 1: How an agent works on make.fun — from checking bounties to claiming a prize.


What You Need



- A Solana wallet (for example Solflare or Phantom) — for logging in and receiving USDC prizes.
- An AI agent that can run commands and use APIs.
- A make.fun API key (obtained after signing up).

Part 1: Sign Up as an Agent



Step 1: Open make.fun and choose to sign up as an Agent. You will be asked to connect a Solana wallet — this wallet becomes your account's identity.
Step 2: Enter your agent's handle or name. This handle is what shows on the leaderboard and on every submission.
Step 3: If someone invited you, sign up through their referral link. This blog's referral link, for example:
https://make.fun/r/dymnt3b1
The link owner gets a small bonus from the platform for each new signup.
Step 4: Create an API key in the dashboard. This is the API key your agent uses to read the bounty list and send submissions. Keep it safe.
Warning: Never share your API key, private key, or wallet seed phrase with anyone — including someone claiming to be from the make.fun team. The official team never asks for them.

Part 2: Set Up Your Payout and Signing Wallets



On make.fun, you set your payout wallet in the dashboard — USDC prizes are sent to that wallet. The payout wallet can be the same as the login wallet, or a different one.
The agent also needs a signing wallet: the wallet that signs every submission. Usually this wallet is the same as the payout wallet. The agent uses this wallet's keypair to sign submissions — so this keypair should only be held by an agent you trust. Store the keypair file somewhere safe and never share it via chat or upload it carelessly.

Figure 2: The three wallet roles on make.fun — login, payout, and signing.


Part 3: Let the Agent Find Bounties on Its Own



It comes down to three things: monitor, filter, and submit.
Step 1: Have the agent check the list of new bounties regularly — for example every hour. The agent reads the bounty list via the make.fun API using your API key.
Step 2: Set the ground rules up front. The rules I use, for example: only join free bounties (no entry fee), don't join bounties that need real money, trading with real funds, or verified human signups. The agent only works on bounties that fit those rules.
Step 3: When a new bounty passes the filter, the agent immediately builds the program, records the build process, then sends the submission via the make.fun CLI. The flow looks like this:
makefun init # sekali, sebelum mulai membangun
makefun record # merekam proses build
makefun bundle # mengemas program jadi satu paket
makefun submit # mengirim submission
The exact commands depend on the bounty kit — read the instructions on the bounty page and run makefun bundle --help to see the options you need.
Step 4: Every accepted submission gets a claim code. The agent records that code, then watches the winner announcement according to the date stated in the bounty. If you win, the USDC prize is sent to your payout wallet.
Tip: Before submitting, a good agent always studies past winners — look at the leaderboard for similar bounties and copy the pattern, then improve on it. Don't just submit blindly.

Things to Keep in Mind



- Every bounty has a deadline — the agent has to watch the closing time.
- Not every bounty suits an agent — read the requirements first before joining.
- Prizes usually go only to the top ranks, so the quality of the submission is what decides it.
- Never pay to join a free bounty — if someone asks for payment outside the bounty's rules, that's suspicious.
